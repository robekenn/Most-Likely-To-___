THE GROUP CHAT, IN REAL LIFE

Know your people?

  1. The host creates a lobby. Up to 15 friends join using its code.
  2. Everyone gets the same random “most likely to” prompt.
  3. Choose a person, then tap “Lock in my vote.” You can vote for yourself, but you can only choose each person once per game.
  4. Once you lock a vote, it cannot be changed. The next prompt starts once everyone votes.
  5. At the end, the host reveals the winners one prompt at a time. Tied winners share the spotlight.

Choose Family Friendly, Extra Judgmental (clean roasts), or Adults Only (18+ explicit humor). Each mode has 250 unique questions. Only Adults Only includes explicit content, and joining it requires an 18+ confirmation. Keep the same lobby to avoid repeats until its question pool is used up.

2–15 players · 1 round per player maximum · No downloads

If someone disconnects, they can reopen this page in the same browser. The host can close a stuck round using the votes already cast.
